# Carnet de produit

## Sprint 1 : Projet original
- Monter et imprimer les pièces de base de la distributrice
- Faire le câblage et tester les moteurs
- Programmer le code de départ
- Faire la démonstration fonctionnelle au prof

## Sprints 2 et 3 : Nos améliorations
- Ajouter une porte sur charnières avec aimants pour faciliter le remplissage
- Mettre une plaque de pression pour détecter quand le produit tombe
- Ajouter un capteur pour avertir quand une rangée est vide
- Installer un bloc d'alimentation 120 V pour brancher dans le mur
- Ajouter un système de paiement par carte RFID
- Mettre des boutons pour sélectionner le produit
- Ajouter un écran simple pour l'utilisateur
- Mettre des pieds antidérapants pour stabiliser la machine
